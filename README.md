📚 Library Management System

A simple and beginner-friendly Library Management System developed using Python. This project allows users to add, view, search, and remove books through a command-line interface.

This project is designed to practice basic Python programming concepts and understand how to manage data using lists.

✨ Features
➕ Add Books: Add new books to the library.
📖 View Books: Display all available books.
🔍 Search Books: Search for a specific book by name.
🗑️ Remove Books: Remove a book from the library.
✅ Duplicate Prevention: Prevent adding the same book more than once.
🚪 Exit Program: Exit the application using the menu.
🛠️ Technologies Used
Language: Python 3
Interface: Command-Line Interface (CLI)
Data Storage: Python Lists
